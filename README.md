# 2026-code-sample-battleship
(Work-in-progress) Oh no! You sunk my battle ship! (Unity)(C#)

This project is acting as a sandbox for me to play with various design patterns.

So far, I've been looking into:
* Model-View-ViewModel
* Strongly typed Ids
* Observable Properties
* Strongly typed entity IDs
